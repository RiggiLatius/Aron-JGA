# assets

Hier kann das Foto von Aron als **`aron.jpg`** abgelegt werden – die App nimmt
diesen Pfad automatisch, solange im Admin-Tab unter *Einstellungen → Bild* nichts
anderes eingetragen ist.

Alternativ (und ohne Repo-Zugriff, direkt vom Handy):
Admin-Tab → *Einstellungen & Getränke* → **📷 Foto hochladen**. Das Bild wird
verkleinert und in der Realtime Database gespeichert und erscheint dann auf allen
Geräten.
