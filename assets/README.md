# assets

**`aron.jpg`** – das Foto von Aron. Die App nimmt diesen Pfad automatisch, solange
im Admin-Tab unter *Einstellungen → Bild* nichts anderes eingetragen ist.

Ersetzen: einfach eine neue Datei mit diesem Namen ablegen. Die Endung ist egal,
die App probiert der Reihe nach `aron.jpg`, `aron.jpeg`, `aron.png`, `aron.webp`
und `aron.JPG` und nimmt die erste, die lädt.

Alternativ (und ohne Repo-Zugriff, direkt vom Handy):
Admin-Tab → *Einstellungen & Getränke* → **📷 Foto hochladen**. Das Bild wird
verkleinert und in der Realtime Database gespeichert, erscheint dann auf allen
Geräten und hat Vorrang vor der Datei hier.
